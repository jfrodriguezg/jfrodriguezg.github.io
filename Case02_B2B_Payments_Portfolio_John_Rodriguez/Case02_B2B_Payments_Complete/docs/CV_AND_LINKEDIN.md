# Case 02 — Credible CV and LinkedIn wording

## English CV (independent project)
**Independent B2B Supplier Payments Financial & Commercial Case | 2026** — Built an editable three-sided financial model comparing bank transfers, integrated payments and virtual cards for a synthetic Colombian distributor (COP 24B annual spend, 120 suppliers). Evaluated acceptance costs, working capital, provider contribution margin and commercial feasibility; developed deterministic synthetic transaction and reconciliation datasets, KPI definitions and a pilot proposal. No live payment integration or commercial deployment claimed.

## LinkedIn project description (English)
**When does B2B payments digitization create shared value?** I built an independent case comparing integrated bank transfers and B2B virtual cards for a fictional Colombian distributor, analyzing buyer savings, supplier acceptance economics, payment-provider contribution and working-capital tradeoffs. The model reveals that a buyer-favorable card proposition can remain commercially unviable when supplier fees exceed measurable benefits. Deliverables: editable Excel model, reproducible synthetic payment data, dashboard, bilingual executive report and supplier pilot design. Sources: official Visa, Mastercard, Rapyd and Colombian payments infrastructure documentation. *Independent simulation—not a production integration.*

## Descripción LinkedIn (español)
**¿Cuándo conviene digitalizar los pagos B2B a proveedores?** Desarrollé un caso independiente que compara transferencias bancarias integradas y tarjetas virtuales para una distribuidora colombiana ficticia. El modelo distingue el beneficio del comprador, los costos de aceptación del proveedor y el margen del prestador, además de incorporar capital de trabajo, conciliación, escenarios y un piloto comercial. Los resultados son sintéticos y no representan una implementación real.
